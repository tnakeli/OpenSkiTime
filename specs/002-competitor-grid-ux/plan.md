# Implementation Plan: Competitor Grid UX Overhaul

**Branch**: `002-competitor-grid-ux` | **Date**: 2026-05-28 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `/specs/002-competitor-grid-ux/spec.md`

## Summary

Restructure the competitor management UX so that competitors live exclusively within the Event Series context (no top-level nav item). Add inline add/edit/delete with a session-only Change Log for undo. Replace the separate Import page with an inline paste workflow (Ctrl+V → highlight → Accept/Discard). Add clipboard copy of selected rows as Excel-ready TSV. Remove the Bib field from the Competition editor.

All import pipeline components from feature 001 (`TsvTokenizer`, `HeaderMapper`, `DiffEngine`, `ImportApplyService`) are reused without modification. No new database migrations are required. Changes are entirely in the UI layer and in-memory session models.

## Technical Context

**Language/Version**: C# 13 on .NET 10 LTS

**Primary Dependencies**: Avalonia UI 11.x, CommunityToolkit.Mvvm 8.x, EF Core 10 + SQLite (unchanged from feature 001)

**Storage**: SQLite via EF Core — no schema changes in this feature

**Testing**: xUnit + FluentAssertions + Avalonia.Headless.XUnit (for UI smoke tests)

**Target Platform**: Windows desktop (Avalonia; Linux-portable architecture maintained)

**Project Type**: Desktop application — UI refactor + in-memory session models

**Performance Goals**: Paste of 50 rows highlights in < 1 second (SC-003). Copy of 50 rows to clipboard < 200 ms.

**Constraints**: Fully offline (no HTTP calls). Session Change Log capped at 200 entries. No new DB migrations.

**Scale/Scope**: Single-user desktop. Competitor lists expected to be 50–500 rows per Event Series.

## Implementation Phases

### Phase 1: Navigation Restructure (US1, US5-bib)

Remove `ImportViewModel` as top-level nav target. Move `CompetitorGridViewModel` under `EventSeriesOverviewViewModel`. Remove Bib from `CompetitionEditorViewModel`.

**Files**: `ShellViewModel.cs`, `ShellWindow.axaml`, `EventSeriesOverviewViewModel.cs`, `EventSeriesOverviewView.axaml`, `CompetitionEditorViewModel.cs`, `CompetitionEditorView.axaml`

**Checkpoint**: Left nav shows no "Import Competitors" item. Competitors section appears under Event Series. Competition editor has no Bib field.

### Phase 2: Change Log + Inline CRUD (US2)

Add `ChangeLogEntry` model, `CompetitorChangeLog` collection to `CompetitorGridViewModel`. Extend `CompetitorRowViewModel` with `RowState`. Wire inline add/edit/delete. Add Change Log UI panel.

**Files**: `CompetitorGridViewModel.cs`, `CompetitorRowViewModel.cs`, `CompetitorGridView.axaml`, `Models/ChangeLogEntry.cs`

**Checkpoint**: Add/edit/delete highlight rows. Change Log panel lists entries. Restore reverts individual changes. Discard All resets grid. Save commits and clears log.

### Phase 3: Inline Paste (US3)

Add `ImportPasteSession` model. Wire Ctrl+V `InputBinding`. Reuse `TsvTokenizer` → `DiffEngine` pipeline. Highlight pasted rows as `PasteHighlighted`. Add Accept/Discard bar.

**Files**: `CompetitorGridViewModel.cs`, `CompetitorGridView.axaml`, `Models/ImportPasteSession.cs`

**Checkpoint**: Ctrl+V pastes without navigation. Changed rows highlighted. Apply commits. Discard reverts.

### Phase 4: Copy to Clipboard (US4)

Add `CopySelectedRowsCommand`. Build TSV with header row + competition columns. Write via `IClipboardService.SetTextAsync`.

**Files**: `CompetitorGridViewModel.cs`

**Checkpoint**: Ctrl+C copies selected rows as TSV. Excel paste produces correct column structure.

### Phase 5: Tests + Polish

Unit tests for Change Log, PasteSession, CopyTsv. Nav structure smoke test. Update `docs/architecture.md`.

**Checkpoint**: All tests green. `dotnet build` clean.
