Before you start

  • Windows 11, 64-bit, is the initial packaging target. Run a complete rehearsal on your actual race computer.
  • The packaged application includes its .NET 10 runtime.
  • ALGE native USB operation needs the appropriate vendor driver and SDK installed separately.
  • Local race operation works offline. Online lookups and cloud live publishing require a connection.

Development releases and event files

OpenSkiTime is currently in pre-release development. New event series use the current development format. Incompatible older development files are rejected without modification; automatic schema upgrades are not available.

Keep backups and retain the version that can open an older series. Rehearse a new version before using it at a race, and update between races.

Trusted downloads

Installers are published through the project’s GitHub Releases. Signing is not enabled yet; see the code signing policy. Release pages include SHA-256 checksums to check that a download matches the published file.

A checksum checks file integrity; it does not provide publisher authentication. Review the release notes before installing.

Something went wrong?

Open an issue on GitHub with the version and steps to reproduce. Use fictional examples and remove credentials, athlete details and private race files.
