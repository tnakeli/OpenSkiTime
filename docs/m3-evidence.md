# M3 entry import and exchange evidence

The rewrite's **Competitors** view now pastes tab-separated rows from the clipboard directly into the competitor grid, following the legacy grid's inline preview. New rows and changed cells are highlighted, and each competition has a compact participation column. Selecting a staged row exposes its participation and imported-bib changes. **Discard import** restores saved rows and removes staged new rows; **Commit import** writes the validated preview in one SQLite transaction. Warnings about uncertain identity require explicit confirmation.

Headers accept surname, first name, combined `Name`, birth year, gender, nation, club and federation/FIS code aliases. Clear comma-separated and uppercase multipart names are split; uncertain splits require confirmation in the inline preview. A competition short label (or `IN:<label>`) maps participation; `Bib:<label>` maps its bib reference. Bare `Bib` targets the competition selected before pasting. `X` enters, `0` removes participation, blank preserves the saved value, and `~` explicitly clears an optional scalar or bib. Quoted tabs, quotes and line breaks round-trip. Export copies or saves the selected grid rows as TSV; false participation exports blank.

The preview binds the source hash, event-series ID and database revision. A changed source, series or revision cannot silently apply the old review. Imported data is validated before mutation. Commit checks final identifier/bib conflicts and stores a source-hash receipt atomically with the rows, so retrying the same paste after reopening cannot create duplicates. Existing event-series files get a backup before the new receipt migration.

Release build and all rewrite tests pass. Tests cover a reachable headless paste/grid-highlight/edit/discard/re-paste/Commit/export workflow, field and entry persistence after reopening, multi-selection export, source-change rejection, warning approval, quoted TSV round trips, blank/clear semantics, duplicate identities, database rollback on a later invalid row, mid-apply cancellation, same-source retry after reopening, a 100-row commit, and M2-to-M3 migration with preserved entries. The earlier separate M3 review was replaced after operator feedback; a 1280 px headless frame of the inline preview was rendered and inspected, then clipped column headers and conflicting Commit panels were corrected. A native Windows visual inspection remains open.

Excel paste is TSV; `.xlsx` file import is outside this milestone. Actual legacy-database conversion, Draw and timing are not part of M3. Existing NU1903 dependency advisories remain.

As in legacy, ordinary edits are already saved before Commit Changes; paste preview uses its separate atomic Commit import action. The headless workflow verifies deletion restore and finalization.
